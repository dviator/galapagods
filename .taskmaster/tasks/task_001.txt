# Task ID: 1
# Title: Create Core Types and Interfaces
# Status: done
# Dependencies: None
# Priority: high
# Description: Define TypeScript interfaces and types for the game state, phases, characters, enemies, and upgrades to establish a strong foundation for the refactored codebase.
# Details:
Create a types.ts file with interfaces for:
- GamePhase type: 'combat' | 'shop' | 'death' | 'lab'
- Character interface with stats, health, abilities
- Enemy interface extending or similar to Character
- Upgrade interface for shop items
- GameState interface containing current phase, characters, enemies, run progress
- Combat-related types for actions, results, etc.

Example structure:
```typescript
export type GamePhase = 'combat' | 'shop' | 'death' | 'lab';

export interface Character {
  id: string;
  name: string;
  health: number;
  maxHealth: number;
  attack: number;
  defense: number;
  // other stats
}

export interface GameState {
  currentPhase: GamePhase;
  playerTeam: Character[];
  enemies: Enemy[];
  runNumber: number;
  // other state
}
```

# Test Strategy:
Verify all interfaces compile correctly and can be imported by other modules. Create sample objects for each interface to ensure they're properly structured.
